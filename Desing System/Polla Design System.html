Polla · Design System

Sistema de tierra refinada.

Una paleta de tonos cálidos, tipografía Mulish con jerarquía clara y componentes pulidos. Construido con tokens semánticos para soportar modo claro y oscuro de forma consistente.

Principios

Cómo se siente Polla.

Cuatro decisiones guían cada componente. Cuando hay duda, vuelve aquí.

01 · Calidez
Tierra antes que neutro

Los grises puros se sienten clínicos. Cada tono base lleva pigmento cálido.

02 · Contraste
Mostaza con propósito

El acento dorado sólo aparece en acciones primarias y datos clave. Se gana, no se reparte.

03 · Jerarquía
Peso, no tamaño

Mulish va de 300 a 900. La densidad de la fuente carga el ritmo, no el tamaño.

04 · Restraint
Lujo silencioso

Bordes finos, sombras suaves, transiciones cortas. La elegancia no grita.
